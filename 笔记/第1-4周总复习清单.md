## 1. 基础语法速查

| 表达式 | 结果 | 类型 | 注意 |
|---|---|---|---|
| `5 / 2` | 2.5 | **永远 float** | 除不尽不加 // 也是 float |
| `5 // 2` | 2 | **永远 int** | 整除；除不尽也返回 int |
| `5 % 2` | 1 | int | 取余 |
| `"abc"[::-1]` | `'cba'` | str | 反转（超高频） |
| `"abc"[1:3]` | `'bc'` | str | 左闭右开 |
| `"abc"[-1]` | `'c'` | str | 最后一个 |
| `int("5") + 3` | 8 | int | input() 的结果必须先转 |
| `"a" * 3` | `'aaa'` | str | str 是重复，list 是重复几遍 |
| `[1,2] + [3]` | `[1,2,3]` | list | list 拼接；`"5"+3` 会 TypeError |
| `{"a":1}.get("b")` | `None` | NoneType | key 不存在返回 None |
| `type({})` | `<class 'dict'>` | | **空大括号是 dict** |
| `type(set())` | `<class 'set'>` | | 空 set 必须写 set() |

## 2. 四大容器对照

| | 括号 | 有序 | 重复 | 可修改 | 典型用途 |
|---|---|---|---|---|---|
| list | `[ ]` | ✅ | ✅ | ✅ | 一串东西：名单/成绩单/待办 |
| tuple | `( )` | ✅ | ✅ | ❌ | 固定记录：一条数据 |
| set | `{ }` | ❌ | ❌ | ✅ | 唯一集合：去重/交集/标签 |
| dict | `{k: v}` | ✅(3.7+) | key唯一 | ✅ | 一张表：按名字查 |

**括号口诀**：方括号=list，圆括号=tuple，**大括号没冒号=set，有冒号=dict**

## 3. 三大容器方法清单

### list
`append(x)` 末尾加一个 | `insert(i,x)` 位置插入 | `extend(其他)` 接一整个容器
`remove(x)` 删指定值(报错) | `pop(i)` 按位置弹出并返回 | `pop()` 弹最后一个
`sort()` 原地排序**返回None** | `reverse()` 原地反转 | `index(x)` 找位置
`count(x)` 数有几个 | `clear()` 清空 | `copy()` 复制
`for i, v in enumerate(lst)` 同时拿下标+值 ⭐

### dict
`d[k]=v` 增/改(**静默覆盖**) | `update(其他)` 批量更新/合并
`d.get(k,默认)` 安全查 | `d.pop(k,默认)` 删并返回 | `d.popitem()` 删最后一组
`del d[k]` 硬删(报错) | `d.keys()/values()/items()` 三种遍历(items最常用)
`k in d` 判断key | `d.setdefault(k,默认)` **没有就新建** | `clear()`
`list(d)` / `set(d)` 直接取 key

### set
`add(x)` 加一个(**不是append**) | `update(其他)` 加多个
`remove(x)` 删(报错) | `discard(x)` 删(不报错) | `pop()` 弹一个
`union/intersection/difference/symmetric_difference` → 运算符 `| & - ^`
**`|` `&` `-` `^` 只对 set 有效，list 必须先 set()**

## 4. 函数要点

- **参数**：位置参数、默认参数、关键字参数
- **返回值**：`return` 之后函数就结束；不写 return 返回 None
- **作用域**：函数内定义的变量，函数外看不见
- ⭐ **可变默认参数陷阱**（考试/面试常考）：
  ```python
  def f(x, lst=[]):   # ❌ 默认值只创建一次，会被所有调用共享
      lst.append(x); return lst
  print(f(1), f(2))   # [1] [1, 2]  ← 第二次带上了上次的 1
  def f(x, lst=None): # ✅ 正确写法
      if lst is None: lst = []
      lst.append(x); return lst
  ```
- **函数不该伸手拿全局变量** → 用参数传进去

## 5. 选型三问

```
① 要按名字/键查东西吗？        → 是 → dict
② 要去重、或求交集并集吗？      → 是 → set
③ 要保持顺序、允许重复吗？      → 是 → list
都不需要 → 默认 list
补充：重复是"脏数据"→set；重复是"有效信息"→list
```

## 6. 推导式三种

```python
[表达式 for 变量 in 容器 if 条件]        # 列表推导式 → list
{表达式 for 变量 in 容器 if 条件}        # 集合推导式 → set
{键: 值 for 键, 值 in 字典.items()}      # 字典推导式 → dict
```
- **前面那一位 = "放进结果的东西"**，可以换成任何表达式
- 过滤用推导式，**别在遍历中 remove()**（会漏删）

## 7. 高频模式（背下来直接用）

```python
# 合并两个 dict
总表 = dict(a); 总表.update(b)

# dict 的值列表 → 真正的 list（"剥皮"）
分数 = list(各科.values())

# 按某个值排序
排名 = sorted(记录列表, key=lambda x: x[1], reverse=True)   # key 不带括号！

# 元组作为一条记录（名字和分数绑在一起，排序才不会错位）
成绩.append((姓名, 总分))

# 嵌套安全查（两层都要默认值）
d.get("人", {}).get("字段", "未填写")

# 统计"只出现一次"
一次 = {w for w, c in counts.items() if c == 1}
```

## 8. 🔴 我的坑（最重要的一章）

### 8.1 变量被覆盖（同一个病根犯了 3 次！）
```python
# ❌ 入参被覆盖成累加器
def sum_list(nums): nums = 0
# ❌ 字典被覆盖成 int → AttributeError: 'int' object has no attribute 'items'
for w, counts in t: print(w, counts)
# ❌ 循环变量泄漏到循环外，出了循环当别的类型用
print(sum_list(b))
```
**规矩：一个变量名从头到尾只干一件事。字典叫 counts，次数叫 c。**

### 8.2 key 不能是 list
```python
d.get(['小刚'], {})   # ❌ TypeError: unhashable type: 'list'
d.get('小刚', {})    # ✅
d[("a","b")] = 1     # ✅ tuple 可以（不可变 → 可哈希）
```

### 8.3 {} 不是空 set
```python
type({})      # dict
type(set())   # set
```

### 8.4 key= 传函数本身，不带括号
```python
sorted(d, key=pinjun)      # ✅
sorted(d, key=pinjun())    # ❌ TypeError: missing 1 required positional argument
```

### 8.5 嵌套安全查必须传 {} 当默认值
```python
d.get("不存在")             # None → 再链式 .get() 会 AttributeError
d.get("不存在", {})         # ✅ 保险垫
```

### 8.6 continue 只能在循环里
顶层写 `continue` → SyntaxError: 'continue' not properly in loop

### 8.7 遍历中不能删除
```python
for w in words:
    if w in stop: words.remove(w)   # ❌ 漏删
words = [w for w in words if w not in stop]   # ✅
```

### 8.8 if 没有 else 配对
```python
if 姓名 in contacts:
    print("已存在，未覆盖")
contacts[姓名] = {...}      # ❌ 照样覆盖了！
if 姓名 in contacts:
    return "已存在，未覆盖"  # ✅
```

### 8.9 字符串方法返回新值，不改原变量
```python
w.lower()        # ❌ 白干
w = w.lower()    # ✅
```

### 8.10 写死的数字是定时炸弹
```python
zongfen / 4              # ❌ 4 科写死了
zongfen / len(fenshubiao)  # ✅
```

### 8.11 类型要统一
```python
"小明": {"电话": 13800138000}    # ❌ 数字
"小红": {"电话": "13900139000"} # ✅ 字符串
```

## 9. 🔧 AI 协作 review 清单（以后的日常）

拿到 AI 写的代码，**按这个顺序查**：

1. **类型对不对**？数字还是字符串？同一字段统一吗？
2. **key 合法吗**？有没有把 list 当 dict 的 key？
3. **`key=` 带括号了吗**？`.get()` 参数带方括号了吗？
4. **有没有硬编码**？（`/4`、`= 0`、`"待改"`）
5. **if 有没有配 else / return**？会不会"提示了但照样执行"？
6. **变量有没有被覆盖**？一个名字是不是承担了两种角色？
7. **缺了什么**？少了 `reverse=True`、少了 `.strip()`、少了 `else` —— **静默错误最致命**
8. **有没有"没跑过"的味道**？自己造一组数据跑一遍，看输出对不对
9. **能不能简化**？`list(set(x))` 的顺序可靠吗？
