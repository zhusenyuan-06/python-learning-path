# 工具链坑 · 使用说明

> 建于 2026-10-27。配套 `工具链坑.py` + `工具链坑.json` + `工具链坑.md`

---

## 一、为什么要单独建一个清单

`错题追踪器.py` 记的是 **Python 概念题**（E01~E20），每周四出卷考。

但这几个月真正让我卡住半天的，往往不是 Python，而是：

| 类型 | 例子 |
|---|---|
| **git 配置** | `curloptResolve` 单值键覆盖、Credential Manager 卡弹窗 |
| **网络排障** | DNS 层 / TCP 层 / 代理层怎么分开查 |
| **Windows 环境** | hosts 权限、GBK 码页、CRLF 换行 |
| **AI 工具使用** | 沙箱权限边界、输出被吞、多轮改表覆盖 |

它们和 Python 错题有本质区别：

| | Python 错题（E 系列） | 工具链坑（T 系列） |
|---|---|---|
| 会不会**反复犯** | 会（所以要复习到不再犯） | 不会（记住了就不用查） |
| 目标 | **每周考到掌握** | **查得到 + 不重复踩** |
| 复习机制 | streak 连续答对才退场 | 踩一次次数+1，自动排序 |

**所以不能用同一套机制。** 硬套只会让周四复习卷变成一锅粥。

## 二、命令

```bash
cd /d/pythonProject/笔记

# 列出全部坑（按踩坑次数排序，次数多的排前面）
python 工具链坑.py ls

# 统计概览（含按标签分布）
python 工具链坑.py stats

# 看某一条详情
python 工具链坑.py show T03

# 新增一条坑
python 工具链坑.py add "标题" "当时看到什么症状" "为什么会这样" "怎么解决" "标签1,标签2"

# 又踩了一次 → 次数 +1，自动更新"最近一次"
python 工具链坑.py hit T03 "17:12 那次推送全挂，又想起这个坑"

# 追加一个新解法（同一个坑，不同环境可能解法不同）
python 工具链坑.py fix T03 "push.sh 里做成 5 轮 × 6 IP 自动重试"

# 改标签（整组替换，不是追加）
python 工具链坑.py tag T03 "git,网络,排查"

# 重新生成 工具链坑.md
python 工具链坑.py render
```

> **标签分隔符**：英文逗号 `,` / 中文逗号 `，` / 中文顿号 `、` 都认。
> 写 `add` 命令时标签顺序是「标题 → 症状 → 原因 → 解法 → 标签」，少写一个参数会被静默忽略，
> 所以建议直接复制上面的模板改。

## 三、什么时候该记一条

**判据（满足任意一条就记）：**

1. **卡了超过 15 分钟** —— 说明下次还会卡
2. **搜了但没搜到** —— 说明答案不在随手能搜到的地方
3. **报错信息有误导性** —— 比如 T02（认证问题表现成网络超时）
4. **差点得出错误结论** —— 比如 T03（差点因为网页崩就改道 GitCode）

**不该记的：**
- 一次性的、粗心的、跟"我怎么想"有关的（那属于错题追踪器的 E 系列）
- 官方文档里写得清清楚楚的（直接查文档更快）

## 四、和周四复习的关系

**周四复习卷只考 Python（E 系列）**，工具链坑不进卷子。

但**每次周四复习前，花 1 分钟扫一眼**：

```bash
python 工具链坑.py ls
```

看有没有**最近一周踩过的坑**（`last_hit` 是最近的）。如果有，说明那个坑还在活跃 —— 下次遇到同类问题会更快想起来。

另外，**凡是"又卡住了同一个东西"，立刻 `hit` 一下** —— 次数会涨，它就会自动排到最前面，提醒你这东西是常客。

## 六、和记忆日志的区别

| | 工具链坑清单 | 记忆日志（`.workbuddy/memory/`） |
|---|---|---|
| 位置 | 仓库内（能推 GitHub、能被搜到） | 本地（不出本机） |
| 面向 | **未来的我**（学习资料） | 助手的上下文 |
| 内容 | 通用解法（换台电脑也适用） | 本机特定事实（路径、ID、时间线） |
| 写法 | 症状 → 原因 → 解法 | 流水账 |

**一个坑如果「换个环境也成立」，就进工具链坑清单；只在本机成立的，进记忆日志。**
