第 1 题  E15  静默错误三件套：能跑但结果是错的（缺 strip / 缺 reverse / 缺 else）【高频 5 次】
  涉及: 静默错误, 核心方法论, 高频
  ❌ 错在这:
    # 代码能跑、输出好看，但结果是错的
    w = w.lower()             # 缺 .strip()
    after = sorted(counts.items(), key=lambda x: x[1])   # 缺 reverse=True
    if 姓名 in contacts: print("未覆盖")   # 缺 return，照样覆盖
  ✅ 应该:
    # 每次写完先问：这行"跑得出来"和"跑得对"是一回事吗？
    w = w.lower().strip(".,!?")
    after = sorted(counts.items(), key=lambda x: x[1], reverse=True)
    if 姓名 in contacts: return "未覆盖"
  --------------------------------------------------------

第 2 题  E01  if 缺 else/return：提示了却照样执行【高频 4 次】
  涉及: 静默错误, 控制流, 函数
  ❌ 错在这:
    def a(name, p):
        if name in contacts:
            print("已存在，未覆盖")
        contacts[name] = {"电话": p}   # 照样覆盖了！
  ✅ 应该:
    def a(name, p):
        if name in contacts:
            return "已存在，未覆盖"   # 有 return 就停在这
        contacts[name] = {"电话": p}
  --------------------------------------------------------
  ✍️ 先自己写一遍再对答案

第 3 题  E02  同一个变量名承担两种角色（被覆盖/泄漏）【高频 4 次】
  涉及: 变量角色, 高频, 函数
  ❌ 错在这:
    def sum_list(nums): nums = 0     # 入参被覆盖成累加器
    for w, counts in t: print(w, counts)  # 字典被覆盖成 int
    print(sum_list(b))                    # 循环变量泄漏到循环外
  ✅ 应该:
    def sum_list(nums):
        total = 0
        for i in nums: total += i
        return total
    
    for w, c in t: print(w, c)   # counts 留给字典，c 给次数
  --------------------------------------------------------
  ✍️ 先自己写一遍再对答案

第 4 题  E03  静默错误：漏了 .strip()，词频被标点污染【高频 3 次】

    for w in words:
