## 功能

- [x] 查询：按姓名查电话/地址/邮箱
- [x] 添加：新增联系人，重复不覆盖
- [x] 删除：删除并回显被删信息
- [x] 统计：列出没填邮箱的人
- [x] 展示：双层遍历打印全部

## 技术点

- **dict 套 dict 的嵌套结构**：外层 key 是姓名，value 又是一个 dict（电话/地址/邮箱）
- **函数封装**：5 个函数，各自职责单一
- **安全查询 `.get(k, default)`**：两层各配默认值，少一层就 AttributeError
- **防止覆盖**：先判断再写入（`if 姓名 in lianxiren: return ...`）
- **循环变量不泄漏**：`for 姓名, 信息 in ...` 不会污染全局命名空间
