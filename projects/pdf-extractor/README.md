# 课件 PDF → 题库 CSV

**把一份 PDF 复习资料，自动拆成能刷的题库表。**

> **一句话**：读 PDF → 逐行认出「哪行是题干、哪行是选项」→ 存成 Excel 能直接打开的 CSV。

---

## 为什么做这个

作品①「课程问答 RAG 机器人」的 **ingest 层**干的就是这件事：把外部资料读进来、拆成结构化数据、存进本地知识库。

这个项目是那条链路的**第一块砖**——而且素材用的是**你自己真实的复习资料**（《计算机网络基础》复习题），不是玩具数据。

---

## 快速开始

```bash
cd projects/pdf-extractor

# 装依赖
python -m pip install -r requirements.txt

# 跑
python 01_提取PDF存CSV.py
```

跑完在 `输出/计算机网络基础_题库.csv` 得到题库表。

> ⚠️ **素材文件不在仓库里**（是版权资料，不能提交）。脚本从你的
> `~/Downloads/《计算机网络基础》复习 题-答案版.pdf` 读取，找不到会直接报错提示。
> 要换素材，改脚本顶部的 `素材PDF` 那一行即可。

## 产物长什么样

跑完得到 **13 道选择题**，每题 4 个选项齐全（已实测核对）。

| 题号 | 题型 | 题干 | 选项A | 选项B | 选项C | 选项D |
|---|---|---|---|---|---|---|
| 1 | 选择 | 1、当某个分组在输出链路发送时… | A、处理时延 | B、排队时延 | C、传输时延 | D、传播时延 |
| 2 | 选择 | 2、（）结构不是局域网拓扑结构。 | A、星型 | B、网状 | C、互联 | D、混合型 |

## 代码结构

| 文件 | 干什么 |
|---|---|
| `01_提取PDF存CSV.py` | 主脚本。三步链路都在这 |
| `requirements.txt` | 依赖（pymupdf） |
| `输出/` | CSV 产物 |

脚本里 5 个判断函数是核心，剩下都是配套：

| 函数 | 干什么 |
|---|---|
| `提取所有行` | PDF → 所有非空行（带页码） |
| `是题目开头` | 判断一行是不是新题开头（**三道闸门**） |
| `是选项开头` | 判断一行是不是选项开头 |
| `拆开多选项` | 一行塞了多个选项时拆开 |
| `是页眉` | 拦掉「第N 页，共M 页」 |
| `拆成题目` | 按上面几个判断，把行组装成题 |
| `写成CSV` | 写文件（utf-8-sig，Excel 双击不乱码） |
| `回读校验` | 读回来核对行数和表头 |

### `是题目开头` 的三道闸门

这是整个项目最容易写错的地方。**第一版我写宽了，解析出 32 道题**（假的），
加上三道闸门后才是正确的 13 道：

| 闸门 | 规则 | 挡掉了什么 |
|---|---|---|
| 1 | 题号只能 1~2 位数字 | `141.14.75.24` 里的 141、`255.255.192.0` 里的 255 |
| 2 | 数字后紧跟「、」或「.」，且「.」后不能再跟数字 | 小数 `2.2*108m/s` 里的 2. |
| 3 | 题号必须紧贴行首 | 句中出现的 `…网络地址为_ _141.14.64.0` |

正则：`r"^\d{1,2}\s*[、]|^[0-9]{1,2}\.(?!\d)"`

## 踩过的坑

- **页码从 0 开始**：代码里 `doc[0]` 是第 1 页，存进 CSV 要 +1
- **CSV 乱码**：写文件必须 `encoding="utf-8-sig"`，普通 `utf-8` 用 Excel 双击会中文乱码
- **PDF 里每页开头有换行**：不丢空行的话，题号判断会被空行打断
- **题号规则写太宽 → 32 道假题**：见上面「三道闸门」
- **选项可能挤在一行**：PDF 里有 `B、一对多通信C、面向报文`（B 和 C 挤一起）、
  `A．最大传输速率　　B．最长帧长　　C．最短帧长　　D．最大站点数`（4 个挤一行），
  必须按选项字母位置切开
- **选项也可能被换行**：`C、具有多个IP 地址，…相同的网络号，并` + `且占用一个主机号`
  是两行，第二行是 C 的续行，不是题干
- **页眉会污染题干**：`第2 页，共8 页` 必须单独拦掉，否则混进题 9 的题干
- **`sqlite3.connect` 路径写错会静默生成 0 字节假库**：connect 前先 assert 路径存在
