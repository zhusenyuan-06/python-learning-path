# 词频统计器 CLI · 依赖说明
#
# 本项目【只用 Python 标准库】，不需要 pip install 任何东西：
#   argparse —— 解析命令行参数（位置参数「文件」+ 可选参数 --top）
#   re       —— 正则表达式（用 [\u4e00-\u9fa5]+|[a-zA-Z]+ 一次切出中英文词）
#   sys      —— sys.exit() 以指定退出码结束程序（文件不存在时退出码 1）
#   pathlib  —— 路径对象（Path.exists() 判断文件在不在、Path.glob() 列出目录里的 txt）
#
# Python 版本要求：3.6+（f-string 需要）
#
# 跑法（在本目录下）：
#   python 词频统计器.py <文件路径> [--top N]
#
#   示例文本.txt --top 5    只显示前 5 名（默认 10）
#   --help                   看完整用法
#
# ⚠️ 示例文本.txt 跟脚本放在同一个目录，直接跑就能看到效果。
#    想统计自己的文件，把路径传进去就行（支持中文路径）。
#
# ⚠️ 读文件时强制用 UTF-8 编码 —— 不写的话 Windows 默认按 GBK 读，
#    遇到中文会报 UnicodeDecodeError。脚本里已经处理好了，
#    如果你的文件是 GBK 存的，请先用记事本「另存为」→ 选 UTF-8。
