## 二、这周最大的 3 个进步

> 下面三条**事实部分已核对**，每条末尾的「我的感受」是本人 10-28 补的观点。

1. **从「学了就忘」到「有机制兜底」**
   10-22 之前学的东西是靠脑子记；现在每个周四 19:00 自动出卷，
   而且「反复犯的题必须复习到不再犯为止」—— 错题从 10 条长到 **20 条**，
   累计犯错 **34 次**被系统盯着（8 条高频、1 条已退场）。
   **本周还多了一个池子**：工具链坑 10 条（git / 网络 / Windows / AI 工具），卡住时先扫它。

   > **我的感受**：这周最让我意外的是：有了这个机制我本以为会增加我的工作量，但是实际应用下来并非如此 —— 它不但没有让我的工作量增加，还让我的复习变得更加精准、更加高效了。这个机制让我避免了「重复复习已经会的东西」和「没完全掌握的东西复习不够」这两个问题。

2. **从「0 个作品」到「有 GitHub 仓库可以被搜到」**
   10-22 建仓库时只有 3 个 commit；今天本地 **16 个 commit、66 个文件**，
   **远端已推 53 个文件**，仓库地址能直接写进简历投递。
   通讯录也拆成了独立作品（`projects/contact-book/`：代码 + README + requirements）。
   **从学知识到能展示，中间这一步通了。**

   > **我的感受**：第一次看到自己的仓库名的时候，首先迎面而来的是一种爽感，或者说一种成就感。但是接踵而至的是自我怀疑 —— 我真的能把我的仓库打造成我理想中的样子吗？我会不会半途而废？这对我或许有是一项极大的考验。

3. **从「不知道自己缺什么」到「知道缺口并排进了具体日期」**
   10-27 看了 3 份真实 JD，对照出 5 项能力缺口，全部落进日程表：
   SQL 11-16~11-19、Linux 11-24~11-25、HTTP/LLM API/RAG 原本就排好了。
   **而且今天发现手上本来就有 SQL 教材**（学校发的 4 份实验文档），
   11-17 的实操已从 SQLite 改成 Navicat+MySQL（跟课程走，能交作业），**总时长一分钟没加**。

## 三、这周踩的坑（新增进错题追踪的）

### 已登记的 Python 坑（20 条，本周新增 10 条）

| 坑 | 一句话说清错在哪 | 现在怎么防 |
|---|---|---|
| **E15 静默错误三件套**（犯 5 次，最顽固）| 能跑但结果是错的：缺 `.strip()` / 缺 `reverse=True` / 缺 `else` | 写完先对照预期输出再提交 |
| **E02 变量角色混用**（犯 4 次）| 入参被覆盖成累加器（`nums` 既是参数又是计数器）| 一个变量只干一件事，累加器另起名 |
| **E01 if 缺 else/return**（犯 3 次）| 提示了"未覆盖"，数据照样被覆盖 | 记住：**`else` 不是"停在这"，只有 `return` 才是** |
| E03 漏 `.strip()` | 词频被标点污染 | 清洗链固定：`.lower()` → `.strip(".,!?")` |
| E13 字符串方法不赋值 | `.lower()` 返回新对象，原变量没变 | 字符串不可变 → 方法结果必须赋值回去 |
| E04 漏 `reverse=True` | 排名是倒的 | 排序前先问「升序还是降序」|
| E16 `x[1]` 取到什么取决于 x 类型 | 以为都是元组，其实是 dict | 拿不准就先 `print(type(x))` |
| E17 浅拷贝 | `dict(a)` 只复制外层，内层仍共享 | 深拷贝用 `copy.deepcopy` |
| E18 静默覆盖 | `update()` 遇到同名 key 直接顶掉 | 先判断再写入 |
| E20 缩进决定归属 | `print` 放循环里每轮都打印 | 缩进是 Python 命门，写完先看缩进 |

| T01 | `http.curloptResolve` 是单值键 | 设 4 次互相覆盖，最后只剩一条 | 用 URL 级 `http.https://<域名>/.curloptResolve`，可多值共存 |

| T05 | bat 必须 CRLF + 纯 ASCII | LF 换行的 bat 静默失败；GBK 码页下中文乱码 | 写完转 CRLF，内容全 ASCII，结尾加 `pause` |

| T10 | 执行即写入的脚本不能拿来「测试」 | 只想验证一下，结果真的写了一���数据 | 测写数据的脚本前先备份，或在副本上测 |
