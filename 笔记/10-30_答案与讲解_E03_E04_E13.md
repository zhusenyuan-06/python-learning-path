## 第 1 题（E03 + E13）· 清洗链的第一步

**实跑输出：**
```
['Apple,', 'banana!', 'apple?', '苹果。', '香蕉，apple.']
```
注意三点：
- `'Apple,'` —— **大写还在**（E13：lower 根本没生效）
- `'Apple,'` —— **逗号还在**（E03：strip 根本没生效）
- `'香蕉，apple.'` —— **中间的逗号还在**（strip 只去首尾）

**③ 两个问题：**

**E13（方法结果没赋值回去）—— 在这一行：**
```python
w.lower().strip(".,!?，。！？")     # ← 白干
```
没有 `w =`，所以：
- `lower()` 返回的**新字符串**被直接丢弃
- `strip()` 在**原串**上操作，返回的新字符串又被丢弃
- `w` **从头到尾没变过**

**E03（漏了标点处理）—— 同一行：**
即使你加了 `w =`，光靠 `lower()` 也不会去掉标点。
**必须显式写 `.strip(".,!?，。！？")`**。

**④ 改写：**
```python
def 清洗(文本):
    结果 = []
    for w in 文本.split():
        w = w.lower().strip(".,!?，。！？")    # ← 赋值 + 完整字符集
        if w:                                  # ← 跳过空串（E19）
            结果.append(w)
    return 结果
```
**实跑：**
```
['apple', 'banana', 'apple', '苹果', '香蕉', 'apple']
```
✅ 大写没了、首尾标点没了。

> 📌 **这一行是「三个错题的交汇点」：**
> `w = w.lower().strip(".,!?，。！？")` 里
> - `w =` → E13
> - `.strip(".,!?，。！？")` → E03
> - 字符集要**中英文都全** → E03 的深水区
> - 后面 `if w:` → E19
>
> **10-29 复习卷里你在这题上漏了两处**（漏停用词 + 字符集不全），
> 今天这题就是把那两处补回来。

## 第 2 题（E13 变体）· 三种「白干」写法

**实跑输出：**
```
A: 'hello'
B: '  Hello  '
C: 'hello'
```

**③ 哪个白干了：`清洗B`**
```python
def 清洗B(s):
    s.lower().strip(" ")     # ← 两步全白干
    return s
```
`lower()` 和 `strip()` 都返回**新字符串**，没有赋值回去，
所以 `s` 还是原来那个 `'  Hello  '`。

**为什么 A 和 C 是对的：**
- **A**：`s = s.lower().strip(" ")` —— **赋值了**，而且是链式的
- **C**：`return s.lower().strip(" ")` —— **直接把结果 return 出去**了，效果等价

**④ 追问的答案：**

> 如果调用方**不看返回值**，白干的那个函数（清洗B）会：
>
> ```python
> s = "  Hello  "
> 清洗B(s)        # 调用了，但没接收返回值
> print(s)        # 还是 '  Hello  ' —— 一点没变
> ```
>
> **最危险的情况**是调用方**以为**它改过了：
> ```python
> 清洗B(s)
> print(len(s))   # 8 —— 调用方以为已经清洗过了，实际还是 8
> ```
>
> **更狠的是**：函数**不报错**。
> 它「成功执行了」，只是什么也没做。
> 调用方永远不会收到任何提示。
>
> **这就是 E13 最阴险的地方** ——
> `w.lower()` 这一行**语法完全正确**、**运行完全正常**，
> 它只是**没有效果**。
>
> 📌 **判断方法：看到一行代码在【调用方法】但【没有赋值、没有 return、没有 print】，
> 就要警觉 —— 它可能什么都没做。**

## 第 3 题（E03）· strip 的字符集要全

**实跑输出：**
```
半吊子: {'hello,': 1, 'world.': 1, 'hello!': 1, 'world?': 1, 'don`t,': 1, '苹果，香蕉': 1}
完整  : {'hello': 2, 'world': 2, 'don`t': 1, '苹果，香蕉': 1}
```

**③ 差别有多大 —— 天壤之别：**

| | 半吊子（`strip("，")`） | 完整（`strip(".,!?，。！？")`） |
|---|---|---|
| `hello` | 散成 `'hello,'` / `'hello!'` **两个词** | 合并成 `'hello'` **一个词，计数 2** |
| `world` | 散成 `'world.'` / `'world?'` **两个词** | 合并成 `'world'`，计数 2 |
| 词条总数 | **6 条**（全是垃圾） | **3 条**（有意义） |

> ⚠️ **注意样本里的 `'don`t,'`** ——
> 它带的是**反引号 `` ` ``**，不在字符集里，所以两版都没去掉。
> **字符集永远不可能列全**，这是下一问要说的。

**④ 中间标点怎么办 —— 这是更深的坑：**

> **`strip` 只去首尾，不去中间。**
> 所以：
> - `'苹果，香蕉'` → strip 后还是 `'苹果，香蕉'`（**中间的逗号还在**）
> - `"don't"` → strip 后是 `"don't"`（**中间的撇号还在**）
>
> **两种处理方式：**
>
> **方式 1：彻底去掉所有标点**（适用于纯分词统计）
> ```python
> import re
> w = re.sub(r"[^\w\s]", "", w)      # 只保留字母数字下划线和空白
> ```
> ⚠️ 但这样 `"don't"` 会变成 `"dont"` —— 词形被破坏了。
>
> **方式 2：保留词内部的标点**（适用于文本分析）
> ```python
> w = w.strip(".,!?，。！？")        # 只去首尾
> w = w.replace("'", "").replace("’", "")   # 单独处理撇号
> ```
>
> **怎么选？取决于你要回答什么问题：**
> - 统计「出现了哪些词」→ **方式 2**（保留 `don't` 的完整性）
> - 统计「纯词频排名」→ **方式 1**（`dont` 和 `don'` 算同一个）
>
> 📌 **10-29 你答的是「去除标点，防止标点占位」** ——
> 这个原理**完全正确**，但**做法不完整**：
> 你只去了一种标点。**「防止标点占位」的目标要求字符集足够全。**

## 第 4 题（E04）· 排名方向

**实跑输出：**
```
[('cherry', 3), ('apple', 5), ('banana', 9)]
```
这是**升序** —— 次数少的排前面，**排名反了**。

**③ 改写：**
```python
def 取前三(counts):
    after = sorted(counts.items(), key=lambda x: x[1], reverse=True)
    return after[:3]
```
**实跑：**
```
[('banana', 9), ('date', 9), ('apple', 5)]
```
✅ 次数高的在前面。

**④ 并列第 3 名会保留几个 —— 一个都不保留：**

> `[:3]` 是**「取前 3 个位置」**，不是「取前 3 名」。
>
> 数据里 `banana` 和 `date` **都是 9 分，并列第 1**。
> 它们占了第 1、2 两个位置，第 3 个位置是 `apple`（5 分）。
> `cherry`（3 分）和 `date`（9 分）……
>
> 等等，实际结果是 `[('banana', 9), ('date', 9), ('apple', 5)]` ——
> **`cherry` 被切掉了**。
>
> **这就是 10-28 你栽过的那个坑：**
> 如果 `apple` 和 `cherry` **并列第 3**（都是 5 分），
> `[:3]` 只会取到**其中一个**，另一个被切掉 ——
> **并列第 3 名的选手丢了**。
>
> **正确做法（阈值法）**：先找到第 N 名的分数，再取所有 >= 该分数的。
> ```python
> def 取前N含并列(counts, n):
>     排序后 = sorted(counts.items(), key=lambda x: x[1], reverse=True)
>     if len(排序后) < n:
>         return 排序后
>     门槛 = 排序后[n - 1][1]          # 第 n 名的分数
>     return [x for x in 排序后 if x[1] >= 门槛]   # 取所有 >= 门槛的
> ```
> **你 10-28 学的「阈值法」就是这个** ——
> `练习/阈值法分步演示.py` 里有可视化拆解。

## 第 5 题（E04 进阶）· sorted 的三种翻车姿势

**实跑输出：**
```
写法1: [('c', 1), ('a', 3), ('b', 7)]
写法2 报错: IndexError : string index out of range
写法3: [('c', 1), ('a', 3), ('b', 7)]
```

**③ 逐个说明：**

**写法 1** `sorted(counts.items(), key=lambda x: x[1])`
- ❌ **少了 `reverse=True`** → 升序，排名反了
- ⚠️ 这题**不会报错** —— 静默错误

**写法 2** `sorted(counts, key=lambda x: x[1])`
- ❌ **忘了 `.items()`** —— `counts` 是字典，直接 `sorted(counts)` 遍历的是**键**（字符串）
- 于是 `x` 是 `'a'`、`'b'`、`'c'` 这些**字符串**，`x[1]` 是在**字符串里取第 2 个字符**
- `'a'` 只有 1 个字符 → **`IndexError: string index out of range`**
- ✅ 这个**会报错** —— 是好事，当场炸给你看

> 💡 **注意报的是什么错**：
> 你可能以为会报 `TypeError: '<' not supported between instances of 'str' and 'int'`
> —— 那是**另一种情况**（如果 key 函数返回了不同类型）。
> 这里报 `IndexError`，因为**在比较之前就先取下标失败了**。
>
> 📌 **这就是「跑一遍」的价值**：报错信息会告诉你它到底死在哪一步，
> 而不是让你猜。

**写法 3** `sorted(counts.items(), key=lambda x: x[1])[:3]`
- ❌ **还是少 `reverse=True`** —— 切片 `[:3]` 在最后，救不了前面排反的顺序
- 它和写法 1 **一模一样错**（少了 `reverse` 那个）

**④ 唯一正确的写法：**
```python
def 取前三(counts):
    return sorted(counts.items(), key=lambda x: x[1], reverse=True)[:3]
```

> 📌 **三种错法的共同点：都在「怎么排」上，而不在「取几个」上。**
> `[:3]` 写得再对，只要顺序反了，结果就还是错的。
>
> **写排序代码的检查清单：**
> 1. `.items()` 了吗？（否则 key 拿到的是键不是值）
> 2. `key=lambda x: x[1]` 对应的是「第 2 个元素」吗？
> 3. **升序还是降序？**（要排名靠前就 `reverse=True`）
> 4. 切片 `[:N]` 会切掉并列第 N 名吗？

## 第 6 题（综合）· 把三题合起来写对

**参考答案：**
```python
def 词频统计(文本, n=3):
    """完整的词频统计器。"""
    counts = {}
    for w in 文本.split():
        w = w.lower().strip(".,!?，。！？")   # ① E13(赋值) + E03(完整字符集)
        if not w:                             # ② E19(空串)
            continue
        if w in 停用词:                       # ③ 停用词
            continue
        counts[w] = counts.get(w, 0) + 1
    排序后 = sorted(counts.items(), key=lambda x: x[1], reverse=True)   # ④ E04(降序)
    return 排序后[:n]
```

```

→ [('python', 3), ('is', 2), ('great', 1)]

（`is` 是停用词被过滤了，`the`/`a`/`an` 同理）

```

```

## 七、三题串起来的一句话

> 📌 **E03 / E04 / E13 其实是同一类问题的三个面：**
>
> | | 表面 | 深层 |
> |---|---|---|
> | E03 | 词被标点污染 | **清洗步骤做少了** |
