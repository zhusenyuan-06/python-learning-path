# 幼儿园菜品配送 · 月度汇总工具

把每月的送货单丢进来，自动按**九类**汇总成一张表。
一个文件里有好几个供应商、表格格式还不一样？没关系，会自动分别汇总、再合并成全园总表。

---

## 一、日常怎么用（每月三步）

**第一步**：把这个月的送货单放进 `input\` 文件夹
（也可以不放，直接把文件拖到 `run.bat` 上）

**第二步**：双击 `run.bat`

**第三步**：打开 `output\` 里新生成的汇总表

黑窗口里会显示对账结果，扫一眼有没有 ✅ 就行：

```
幼儿：464 行，合计 31,553.19  ✅ 与表内小计一致
教师：65 行，合计 3,866.99  ✅ 与表内小计一致
```

---

## 二、输出的表里有什么

表里每个供应商占两页，最后再给一份全园合并的总表。比如九月是锦源 + 绿禾两家：

| 工作表 | 内容 |
|---|---|
| 锦源汇总 | 每个菜品的数量、送货次数、加权均价、总金额、占比；按类分组，每类带小计 |
| 绿禾汇总 | 同上 |
| 锦源日期 / 绿禾日期 | 每个送货日花在九类上各多少钱，带自然周小计 |
| **全园汇总** | **两家合并**：同一个菜不管谁送的，加在一起算总数 |
| **全园日期** | 合并后按日统计 |
| 类别总览 | 九类在各家 + 合计的金额对比 |
| **图表** | 占比饼图 + 各月趋势 + 每日趋势 |
| 待补充 | 没归上类的品名（有才会出现） |

> 全园汇总那页「编号」是空的——各家编号不通用，合并时按**品名**相加。

### 多个供应商怎么放

**一个 Excel 文件里，一个供应商一个 sheet，sheet 名就写供应商名**：

```
云湖湾2026.9月电子送货单.xlsx
  ├─ 锦源      （或 锦源9月）
  └─ 绿禾      （或 绿禾9月）
```

两家表格格式不一样没关系——有没有商品编号、有没有「实收数量」，工具都能读。
（比如绿禾那张表既没编号也没实收数量，照样能算。）

sheet 名写歪了就在 `config\categories.yaml` 的 `supplier_aliases` 里纠正一条：
```yaml
supplier_aliases:
  "幼儿 9月": 锦源     # 这张表 sheet 名写的是人群，其实是锦源送的
```

### 图表页说明

图表是 Excel 原生图表，不是图片，点上去能改样式、能看数据点。
**图表的数据块就放在同一张表的第 57 行往下**，别删那几块，删了图就空了。

| 图 | 看什么 |
|---|---|
| 锦源 / 绿禾 / 全园合计 各类占比（饼图 ×3） | 钱主要花在哪类上、两家结构差多少 |
| 各月采购总额趋势（柱图） | 一个月比一个月贵还是便宜 |
| 各月类别结构（堆叠柱图） | 结构有没有变，比如水产是不是涨了 |
| 本月每日采购额趋势（折线） | 这个月哪几天送得多 |

前两个月只有一根柱子很正常——**跑的月份越多，趋势图越好看**。

## 三、月度台账（趋势图的数据来源）

每次出汇总表，工具会自动把本月各类金额记一笔到 `data\月度台账.csv`：

```
月份,人群,类别,金额,更新时间
2026-05,幼儿,蔬菜,6973.19,2026-10-28 16:55
...
```

- **同一个月重跑会覆盖**，不会重复计数
- 想看历史直接双击这个 csv（Excel 能打开，中文不乱码）
- 想改某个月的金额，改 csv 后重跑那个月就行（重跑会覆盖，所以要在跑之前改，或改完别再跑那个月）
- 想清空重来：把 `data\月度台账.csv` 删掉

## 四、九个类别

蔬菜 · 豆制品 · 水产和肉类 · 米面 · 水果坚果 · 蛋 · 奶制品 · 干货调味 · 油

（这套是幼儿园自己的分类，写在送货单表尾。）

### 想加一个新类别？四步，全程不用碰代码

编辑 `config\categories.yaml`，**加类、给色、加词、迁移**，一次搞定：

```yaml
categories:            # ① 加一行，位置 = 汇总表里的显示顺序
  - 蔬菜
  - 凉菜              # ← 新类别

colors:                # ② 给它一个图表颜色
  凉菜: "#7FB3D5"

keyword_rules:         # ③ 加关键词（要排在比它更宽泛的规则前面）
  - category: 凉菜
    keywords: [凉拌, 拍黄瓜, 泡椒]

migrations:            # ④ 把已经归好类的老菜挪过来（不写这步，打过 y 的老菜挪不动）
  - to: 凉菜
    match: [凉拌, 拍黄瓜]
```

存盘，重跑，完事。`migrations` 跑一次就会改写归类表，之后留着也无害。

> ⚠️ 关键词**别写太宽泛**。当初加「豆制品」时如果只写一个"豆"字，
> 土豆、荷兰豆、毛豆、绿豆芽全会跑错。现在这几样已经用 `overrides` 钉死成蔬菜了。

## 五、归类不对怎么办

打开 `config\mapping.xlsx`，改「类别」列，改完在「确认」列填 `y`。

**确认过的行以后永远听你的**，不会被自动规则改回去。

遇到新菜品（表里第一次出现的品名），工具会自动归到「待定」并单列在「待补充」工作表里，
你去 mapping.xlsx 补一下类别，重跑一次就好。

---

## 六、想改归类规则

编辑 `config\categories.yaml`：

- `overrides`：**你亲自定的规则**，优先级最高（比如"纸碟算干货""薯条算水果坚果"）
- `keyword_rules`：关键词自动匹配，从上往下命中即停，越具体的写越靠前
- `migrations`：一次性迁移，用来把确认过的老菜挪到新类别

改完不用动代码，重跑即可。

### 同事整理好了一份归类表，怎么导进来

```bat
python src\import_mapping.py "C:\某路径\mapping.xlsx"
```

会自动清洗：删掉被误当菜品的表内分类标题、统一写歪的类别名、
合并编号前导零造成的重复行（00011 和 11 是同一个菜）、并按 `migrations` 做迁移。
**原文件不会被动**，只写 `config\mapping.xlsx`。

## 七、几个要紧的口径

1. **金额以「实收数量 × 单价」逐行重算为准**，不直接采信表里的金额列。
2. **均价 = 总金额 ÷ 总数量**（加权），因为同一个菜一个月里可能调价。
3. **数量按「编号 + 单位」汇总**，单位不同的不会硬加在一起。
4. **表尾那个"合计"数字不可信**。5 月表里的 98,526.56 是重复计数的，
   真实全月是 35,420.18（= 幼儿 31,553.19 + 教师 3,866.99）。
   原因就写在那个单元格的公式里：`=SUM(J3:J718)` 把小计行 J467 又加了一遍。
   工具以重算结果为准，并会跟表内小计自动对账。

## 八、命令行用法

```bat
run.bat                      扫 input\ 里最新的表并汇总
run.bat "D:\某路径\6月表.xlsx"  指定某张表

python src\run.py check       只读取+对账，不出汇总表
python src\run.py mapping     只生成/更新品名归类清单
python src\run.py report      出汇总表
```

## 九、目录说明

```
<项目目录>\
  config\     类别定义(categories.yaml) + 品名归类表(mapping.xlsx)
  input\      放每月的原始送货单（只读，不会被改）
  output\     汇总结果，文件名带时间戳，不覆盖历史
  data\       月度台账.csv（趋势图的数据来源，自动生成）
  src\        脚本
  run.bat     双击启动
```

  app.py          给同事用的交互入口（双击出菜单 / 拖文件就跑），打包时打的是它
  重新打包.bat     改完代码后重新生成 exe
  交付包\          给同事的成品（文件夹 + zip）

原始文件**永远不会被修改**，输出都带时间戳，跑错了也不会毁数据。

## 十、打包成 exe 给同事（同事电脑不用装任何东西）

**成品**：zip 已放到桌面（`幼儿园菜汇总工具.zip`，约 35MB，解压后 90MB）。
整个文件夹拷到任何一台 Windows 电脑上都能跑，不需要 Python。
（项目里的 `交付包\` 副本已清理，需要时重新打包即可。）

**同事的用法**：把送货单拖到 `幼儿园菜汇总.exe` 上，或放进 `input\` 后双击 exe 按 1。

**自己要重新打包时**：双击 `重新打包.bat`。

几个要点：

1. **exe 旁边必须有 `config\`**——同事要能自己改 `mapping.xlsx`，所以归类表不能封进 exe。
   万一 config 丢了，程序会自动从内置那份复制一份出来。
2. **打包环境用完就删了**：做 exe 时用的是 `.buildenv\`（194MB 的隔离环境，
   基于你的 `<Python安装目录>\python.exe` 建的），你原来的 Anaconda **一个字节都没动过**。
   要重新打包 exe，先重建这个环境（两条命令，约 1 分钟）：

   ```bat
   <Python安装目录>\python.exe -m venv .buildenv
   .buildenv\Scripts\python.exe -m pip install pandas==2.2.2 numpy==1.26.4 openpyxl xlsxwriter pyyaml pyinstaller
   ```

   然后双击 `重新打包.bat`。日常用项目（跑汇总）**完全不需要它**。
3. **踩过的坑**：Anaconda 的 DLL 不在标准位置，`_ctypes` / `pyexpat` 会连着报
   "DLL load failed"。解决办法是显式带上这 7 个 DLL：
   `LIBBZ2.dll` `ffi.dll` `libcrypto-3-x64.dll` `libexpat.dll` `liblzma.dll`
   `libssl-3-x64.dll` `sqlite3.dll`（都在 `<Python安装目录>\Library\bin`）。
   **换电脑或重装 Python 后，重新打包.bat 里这些路径要跟着改。**
4. **exe 没有数字签名**，360 / 火绒可能误报，让同事点"允许"或加白名单。

## 十一、数据说明（本仓库已脱敏）

这个工具最初是为一家幼儿园的菜品配送做的，**仓库里的数据是脱敏后的版本**：

| 处理对象 | 做法 |
|---|---|
| 园所名称 | 换成虚构名 |
| 供应商名称 | 换成虚构名 |
| 联系电话 / 地址 | 整块替换 |
| 单价、金额、加权均价、占比 | **保序扰动**：保留「哪个菜贵、哪个菜便宜」的相对关系，绝对值全部换成另一套账 |
| 月度台账金额 | 整体缩放，趋势形状不变 |
| 344 种食材、9 大类规则、两个 sheet 的不同表格格式 | **一字未动** —— 这是这个项目的核心价值 |

所以你在这里看到的每一个数字都和真实业务无关，但**所有计算逻辑、归类规则、格式兼容处理都是原样可跑的**。

脱敏脚本不在本仓库里（脚本里含有真实名称的对照表）。但仓库自带一个**通用敏感信息自检**：

```bat
python _检查敏感数据.py
```

它不依赖任何具体企业名，按【手机号 / 固话 / 企业全称 / 详细地址】四种通用模式扫全仓库，
所以它自己也不会成为泄密点。跑一下是 [OK] 就说明没漏。

如果你想自己造一份测试数据：

```bat
python src\make_sample.py --month 2026-06
```

它会基于 `input\` 里的表生成一个下个月的模拟送货单（换日期、单价数量小幅浮动、故意掺入几个没归过类的新品名，用来演示「待补充」提醒）。
