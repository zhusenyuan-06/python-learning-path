## 一、这 2h 到底解决什么问题

**一句话：正则 = 给你一套「按规则找东西」的语法。**

| 你要做的事 | 不用正则 | 用正则 |
|---|---|---|
| 找手机号 | `if "138" in 文本`（只能找固定串） | `r"1[3-9]\d{9}"` |
| 找所有邮箱 | 循环 + `split("@")` + 判断 | `r"[\w.+-]+@[\w-]+(?:\.[\w-]+)+"` |
| 提取日期 | 手动切 `-` 再判断 | `r"\d{4}-\d{2}-\d{2}"` |
| 校验格式 | 一堆 `if` | `re.fullmatch(r"...", s)` |
| 替换文本 | `str.replace` 只能替固定串 | `re.sub(模式, 替换内容, 文本)` |

**和已有知识的关系：**

- `str.find` / `str.replace` ↔ 正则 —— **前者找「这个字面量」，后者找「这一类」**。
- 你在 11-10 的词频统计器里其实已经用过 `re.split(r"[\s,，。]+", 文本)` —— 那就是正则。
- `os/datetime` 那节课学到 `strptime`（字符串 → 时间对象）——
  **本节课的正则是它的上游**：先用正则从一大坨文本里把日期「抠出来」，
  再用 `strptime` 把字符串转成真正的时间对象。两步连起来才是完整链路。

**为什么今天必须做：** 11-09 晚上那项「提取文本中的日期/邮箱」，
它的难点全在正则这一层。datetime 会了，正则不会，晚上那一项还是做不动。

## 二、正则的基本零件：模式 + 匹配

**模式（pattern）** = 你写的规则字符串，比如 `r"\d{4}-\d{2}-\d{2}"`

**三个必会函数**（`import re` 之后用）：

| 函数 | 干什么 | 返回什么 |
|---|---|---|
| `re.search(模式, 文本)` | 找**第一个** | `Match` 对象；**找不到返回 `None`** |
| `re.findall(模式, 文本)` | 找**全部** | **列表**（最常用） |
| `re.finditer(模式, 文本)` | 找**全部** | 迭代器，每个元素是 `Match` 对象 |
| `re.match(模式, 文本)` | 只从**开头**匹配 | `Match` 或 `None` |
| `re.fullmatch(模式, 文本)` | **整个字符串**必须匹配 | `Match` 或 `None` |
| `re.sub(模式, 替换内容, 文本)` | 按规则替换 | 新字符串 |

**实跑输出：**

```
search  -> <re.Match object; span=(29, 40), match='13800138000'> | .group() = 13800138000 | .start() = 29
findall -> ['13800138000']
findall(邮箱) -> ['zhangsan@mail.com', 'lisi@abc.cn']
  finditer: 138 位置 (29, 32)
  finditer: 001 位置 (32, 35)
  finditer: 380 位置 (35, 38)
```

⚠️ **两个必须记住的点：**

1. `search` 返回的**不是字符串**，是 `Match` 对象。
   要拿到文本必须 `.group()`（等价 `.group(0)`），要拿位置用 `.start()` / `.span()`。
2. `search` **找不到会返回 `None`** —— 直接 `.group()` 会炸 `AttributeError`。
   这是典型的「静默错误变崩溃错误」的场景：

```python
m = re.search(r"\d+", "abc")     # m 是 None
print(m.group())                  # ❌ AttributeError: 'NoneType' object has no attribute 'group'
```

**正确写法永远是先判空：**

```python
m = re.search(r"\d+", 文本)
if m:                              # ← 一定要判
    print(m.group())
```

## 三、元字符速查表（最常用的一半）

| 符号 | 含义 | 实跑示例 |
|---|---|---|
| `.` | **任意一个**字符（**不含换行**） | `r"a.c"` |
| `^` | 行首 | `r"^\w+"` |
| `$` | 行尾（⚠️ 不是字符串末尾，见第八节坑2） | `r"\w+$"` |
| `\d` | 一个数字 `[0-9]` | `r"\d+"` |
| `\D` | 一个非数字 | |
| `\w` | 一个单词字符（字母/数字/下划线/**中文**） | `r"\w+"` |
| `\W` | 一个非单词字符 | |
| `\s` | 一个空白（空格/换行/制表符） | `r"\s+"` |
| `\S` | 一个非空白 | |
| `[abc]` | **字符集**：a、b、c 中任意一个 | `r"[a-z]+"` |
| `[^abc]` | **取反**：除了 a、b、c 之外 | `r"[^a-z]+"` |
| `[a-z]` | 范围 | |
| `|` | **或**（左右任一） | `r"cat|dog"` |
| `( )` | 分组 | |
| `\` | 转义（把特殊字符当普通字符） | `r"a\.c"` |

**实跑输出：**

```
re.findall(r'\d+', s)      = ['123', '456', '789']
re.findall(r'\w+', s)      = ['abc123', 'def456', 'GHI789']
re.findall(r'[a-z]+', s)    = ['abc', 'def']
re.findall(r'[^a-z]+', s)   = ['123 ', '456\nGHI789']
re.findall(r'^\w+', s)     = ['abc123']
re.findall(r'\w+$', s)     = ['GHI789']
注意：. 不匹配换行 -> []
      [\s\S] 才跨越换行 -> ['a\nc']
```

**📌 一句话记忆**

> **带反斜杠的（`\d \w \s`）是「一类」，方括号的（`[a-z]`）是「一个范围」，圆点的（`.`）是「任意一个但不含换行」。**

## 四、量词：重复几次 + 贪婪 vs 非贪婪

| 量词 | 含义 |
|---|---|
| `*` | 0 次或多次 |
| `+` | **1 次或多次**（最常用） |
| `?` | 0 次或 1 次 |
| `{m}` | 正好 m 次 |
| `{m,n}` | m 到 n 次 |
| `{m,}` | m 次及以上 |

**实跑输出：**

```
贪婪   r'<p>.*</p>'      = ['<p>hello</p><p>world</p>']
非贪婪 r'<p>.*?</p>'     = ['<p>hello</p>', '<p>world</p>']
数量   r'a{2,3}'         = ['aa', 'aaa', 'aaa']
可选   r'colou?r'        = ['color', 'colour']
至少一次 r'\d+'          = ['1', '22', '333']
```

### ★ 贪婪 vs 非贪婪（今天最重要的一节）

- `.*` 是**贪婪**的：能吃多少吃多少 → `<p>.*</p>` 把**两个标签都吞了**，只匹配出 1 个大块。
- `.*?` 是**非贪婪**的：够用就停 → 每个标签单独匹配出 2 个。

> **记法：`?` 加在量词后面 = 「够用就停」。**
> `.*?` `+?` `??` `{m,n}?` 都是非贪婪。

**什么时候必须用非贪婪：** 只要你想匹配的内容是**分隔符之间**的东西，
或者一对成对出现的符号（引号、括号、标签）—— 贪婪几乎一定会多吞。

## 五、分组与捕获

`( )` = 分组，同时会把匹配到的内容**捕获下来**。

| 写法 | 含义 |
|---|---|
| `(...)` | 捕获组，可以 `.group(1)` 拿 |
| `(?:...)` | **非捕获组** —— 只分组不捕获（不影响 findall 的返回） |
| `(?P<名字>...)` | **命名组**，`.group("名字")` 拿 |
| `(?P=名字)` | 反向引用，匹配前面同名组的内容 |

**实跑输出：**

```
全部匹配 r'(\d{4})-(\d{2})-(\d{2})' -> [('2026', '11', '14')]
⚠️ 有捕获组时 findall 返回的是【组内容】，不是整个匹配！
无捕获组 r'(?:\d{4})-(\d{2})-(\d{2})' -> [('11', '14')]
命名组 m.group('y') = 2026 | group('m') = 11
group() 全部 = ('2026', '11', '14')
```

### ★ 这里有个大坑，必须理解透

`re.findall(r"(\d{4})-(\d{2})-(\d{2})", log)` 返回的是
`[('2026', '11', '14')]` —— **是元组的列表**，不是 `['2026-11-14']`！

**规则：**
- 模式里**有 1 个**捕获组 → 返回**字符串列表**（那 1 个组的内容）
- 模式里**有 N 个**捕获组 → 返回**元组列表**（每组一个元素）
- 模式里**没有**捕获组 → 返回**整个匹配**的字符串列表

**所以：只要你不是真的要组内容，就用 `(?:...)` 包起来。**

## 六、re.sub 替换 + re.compile + 标志位

### 6.1 sub：用正则批量替换

`re.sub(模式, 替换内容, 文本)` —— 替换内容里可以用 `\1` `\2` 引用捕获组。

**实跑输出：**

```
原文: 会议 2026/11/14 和 2026.11.14 和 2026年11月14日
统一后: 会议 2026-11-14 和 2026-11-14 和 2026-11-14
```

对应模式：`r"(\d{4})[/.年](\d{2})[/.月](\d{2})日?"` → 替换成 `r"\1-\2-\3"`

（命名组要用 `\g<名字>` 这种写法）

### 6.2 compile：同一个模式用多次时，先编译

**实跑输出：**

```
编译后 findall: ['2026-11-14']
编译后 search : 2026-11-14
编译后 sub    : 日期是 2026-11-14 哦
```

```python
pat = re.compile(r"\d{4}-\d{2}-\d{2}")
pat.findall(文本)     # 等价 re.findall(模式, 文本)
pat.search(文本)      # 等价 re.search(...)
pat.sub("替换", 文本)  # 等价 re.sub(...)
```

**什么时候必须用：** 一个模式在循环里反复用 → 编译一次省时间。
只用一个地方 → 直接 `re.findall` 更省事，**不用为了用 compile 而用**。

### 6.3 标志位 flags

| 标志 | 作用 |
|---|---|
| `re.IGNORECASE` | 忽略大小写 |
| `re.MULTILINE` | `^` `$` 变成**每行**的行首行尾 |
| `re.DOTALL` | `.` 也匹配换行 |
| `re.VERBOSE` | 模式里可以换行加注释（长正则用） |

**实跑输出：**

```
IGNORECASE: ['ABC', 'abc', 'AbC']
MULTILINE: ^ 每行行首 -> ['one', 'two', 'three']
DOTALL   : . 匹配换行 -> ['a\nb']
```

## 七、转义：特殊字符要加反斜杠

正则里 `.` `*` `+` `?` `(` `)` `[` `]` `{` `}` `^` `$` `|` `\` 都有特殊含义。
要匹配它们本身，就得加 `\`。

**实跑输出：**

```
直接匹配 a.c : ['a.c']
re.escape     : a\.c -> ['a.c']
re.escape 整句: 价格是\ 3\.5\ 元 -> ['价格是 3.5 元']
```

**`re.escape(s)` = 把字符串里所有正则特殊字符自动加反斜杠。**
用途：你要匹配的是一段「用户输入的、不确定的文本」时（比如从 CSV 读到的关键词），
直接 `re.escape()` 最省事，比自己判断哪些字符特殊靠谱。

## 八、实战：提取日期 / 邮箱 / 手机号

**这就是 11-09 晚上那一项的核心。** 先看每条正则怎么组装：

| 要提的东西 | 正则 | 拆解 |
|---|---|---|
| `2026-11-14` | `r"\d{4}-\d{2}-\d{2}"` | 4 位数字 + `-` + 2 位 + `-` + 2 位 |
| `2026年11月13日` | `r"\d{4}年\d{1,2}月\d{1,2}日"` | 月日可能 1 位或 2 位 → `{1,2}` |
| 邮箱 | `r"[\w.+-]+@[\w-]+(?:\.[\w-]+)+"` | 用户名 + `@` + 域名 + **至少一段** `.xxx` |
| 手机号 | `r"1[3-9]\d{9}"` | `1` 开头 + 第二位 3-9 + 再 9 位数字 |

**实跑输出：**

```
日期(\d{4}-\d{2}-\d{2}) : ['2026-11-14']
日期(年月日)            : ['2026年11月13日']
邮箱(简版)             : ['zhang.san+tag@company-mail.com', 'wangwu@school.edu', 'li@163.com']
⚠️ 简版把 wangwu@school.edu.cn 截成 wangwu@school —— 域名多段要用 (?:\.[\w-]+)+
邮箱(完整版)           : ['zhang.san+tag@company-mail.com', 'wangwu@school.edu.cn', 'li@163.com']
手机号(1开头11位)      : ['13800138000']
```

### ★ 我自己写错的那一处（重点讲）

我第一版邮箱正则写的是 `[\w.+-]+@[\w-]+\.\w+`，
看起来没问题，但**把 `wangwu@school.edu.cn` 截成了 `wangwu@school`**。

**原因拆解：**

```
[\w.+-]+     → zhang.san+tag     （用户名部分，+ 贪婪吃到 @ 之前）
@            → @
[\w-]+       → school            （域名的第一段）
\.\w+        → .edu              （一个点 + 一段）    ← 问题在这！
                                       .cn 没人管了
```

**修法：** 域名点后面可能是**多段**（`.edu.cn`、`.co.uk`、`.com.cn`），
所以要写成 `(?:\.[\w-]+)+` —— 「一个点 + 一段」这个组合**重复 1 次或多次**。

> **📌 一句话记忆**
> **写正则拿不准「这段到底能有多长」，就想想「它会不会出现第二遍」。**
> 会重复的 → 用 `+` 或 `{m,n}` 撑开。

### 下一步：接上 datetime

正则抠出来的是**字符串**，还不是时间对象。要变成能做减法的 datetime：

```python
import re
from datetime import datetime

文本 = "2026-11-14 补做 re 正则基础"
日期串 = re.search(r"\d{4}-\d{2}-\d{2}", 文本).group()   # '2026-11-14'
时间对象 = datetime.strptime(日期串, "%Y-%m-%d")           # datetime(2026, 11, 14, 0, 0)
```

**这条链路今天要走通：** `re.search` → `.group()` → `strptime` → 时间对象。
**注意 `.group()` 之前必须判 `None`**（见第二节）。

## 九、五个最容易踩的坑（全部实跑验证）

### 坑1：空匹配 —— `*` 可以匹配 0 次

```
re.findall(r'a*', 'bb') = ['', '', '']   <- 全是空串
```

`a*` 意思是「0 次或多次」，在每个位置都能匹配「0 个 a」。
所以 `bb` 里匹配到 3 个空位置。

**对策：** 想至少 1 次就用 `+` 或 `{1,}`，别用 `*`。

### 坑2：`$` 是**行尾**，不是字符串末尾

```
re.search(r'\w+$', multi) = 第二行  <- 匹配到的是「第二行」的行尾
   对照 'hello\n'：
     r'\w+$'  -> hello  <- 匹配的是【第一行】的行尾
     r'\w+\Z' -> None  <- 字符串末尾是换行符，\Z 找不到
```

**`$` 和 `\Z` 的区别：**
- `$` → 每一行的末尾都算（除非加 `re.MULTILINE` 才有区别，但 `$` 本身**默认就是行尾**）
- `\Z` → **整个字符串**的末尾

**对策：** 要「整个字符串必须长这样」，用 **`re.fullmatch()`**，最省心。

### 坑3：`.` 不匹配换行

```
re.findall(r'a.c', 'a\nc') = []  <- 匹配不到
```

`.` 默认只匹配「除换行以外的任意字符」。
要跨行就用 `[\s\S]`（或加 `re.DOTALL` 标志）。

**这条对「提取日志里的多行内容」特别重要** —— 你的 api-demo 日志解析会撞上。

### 坑4：字符类里 `-` 的位置有讲究

```
r'[a-c-e]' 匹配: ['b', '-']  <- - 在中间是范围 a到e
r'[-a-c]' 匹配: ['b', '-']  <- - 在开头就是普通字符
```

- `-` 在**中间** → 被当成范围符（`a-c` = a到c，`-e` = 减号或 e）
- `-` 在**开头或结尾** → 就是普通字符

**对策：** 想匹配减号本身，写 `[a\-c]`（转义）或把 `-` 放最后。

### 坑5：Python 3 的 `\w` 和 `\d` 默认是 Unicode

```
r'\w+' 匹配中文: ['中文abc']
r'\d+' 匹配全角数字: ['１２３']
```

**这通常是你想要的**（中文文本里 `\w` 能匹配中文，省事）。
但如果你要**严格只认 ASCII 数字**，得写 `re.ASCII` 标志，或者用 `[0-9]`。

## 十、今天真正要记住的 5 件事

1. **`search` 返回 `Match` 对象，要 `.group()` 取值；找不到是 `None`，用之前先判空。**
2. **`\d` `\w` `\s` 是「一类字符」，`[a-z]` 是「范围」，`.` 是「任意一个但不含换行」。**
3. **`.*` 贪婪会多吞，匹配「一对符号之间的内容」要用 `.*?`。**
4. **`findall` 里有捕获组就返回「组内容」，没有才返回整个匹配 —— 想返回整个就用 `(?:)`。**
5. **量词后加 `?` = 够用就停；特殊字符要 `\` 转义或用 `re.escape`。**
