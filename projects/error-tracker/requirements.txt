# 错题追踪器 · 依赖说明
#
# 本项目【只用 Python 标准库】，不需要 pip install 任何东西：
#   json —— 错题池的序列化 / 反序列化（错题追踪.json）
#   os   —— 路径处理（__file__ 定位数据文件所在目录）
#
# Python 版本要求：3.8+（f-string 需要 3.6+）
#
# 跑法（在本目录下）：
#   python 错题追踪器.py stats          # 看错题池概况
#   python 错题追踪器.py ls              # 看待复习清单
#   python 错题追踪器.py plan 6          # 生成本周复习卷
#
# ⚠️ 数据文件跟着脚本走（错题追踪.json 和自动渲染的 错题追踪.md 都在本目录），
#    所以在哪个目录敲命令都能正常工作。
